One-line: the booking call to action — use `primary` for the single most important action on screen, `outline` for secondary, `ghost` for quiet inline links.

```jsx
<Button variant="primary" size="lg" href="https://square.site/book/0Q0830DRJQKZ6/shatoya-desree-llc-lawrenceville-ga">Book Appointment</Button>
<Button variant="ghost" href="#gallery">See the work</Button>
```

Never place two `primary` buttons in one viewport. On the ivory (`.sd-on-bone`) bands use `inverse` or `outline`. Label copy is title case, rendered uppercase by CSS — write "Book Appointment", not "BOOK APPOINTMENT".
